# 프로젝트 한 장 기획표 — 수정 문안

물류센터 전체 공정의 자동화와 상태 가시화가 중심이다. AMR은 파레트 운반·상차를 담당하는 하위 설비로 구성한다. 이 문서는 기획표에 옮겨 적을 문안이며 SRS가 아니다.

외형은 실제 물류센터에 가까운 산업 설비·창고와 PBR 재질을 우선한다. 현재 URP를 기준으로 무료·기존 자산부터 검토하고, 저면수 단순 색상 에셋은 프로토타입용으로 구분한다. HDRP 전환이나 유료 에셋 구매는 확정하지 않았다.

분류 레인 3개의 하강 구간은 **무동력 경사 롤러 컨베이어**로 구성한다. 박스가 자중으로 이동하는 구조이며 일반 벨트 컨베이어로 대체하지 않는다. 메인 순환 컨베이어의 구동 방식과 구분한다. 경사·롤러 간격·구름 저항·끝단 감속과 스토퍼는 박스 바닥 치수·질량에 맞춰 검증한다.

## 1. 기본 정보

- 팀명: 6팀 (LYN)
- 제목: 물류센터 자동 분류·적재·출하 디지털 트윈
- 역할 분담: 공정 환경·컨베이어 분류 / FR5 파레타이징 / AMR 운반·상차 / 공정 제어·대시보드

## 2. 공정 한 문장

박스 투입 → 타원형 메인 컨베이어 순환 → QR 판독 → 수용 가능한 목적 레인의 무동력 경사 롤러로 분기 → ML로 도착 박스의 위치·회전 인식 → 레인별 FR5 진공흡착 파레타이징 → AMR 지게차로 파레트 운반·차량 상차 → 차량 만재 시 출발 및 교체. QR이 없는 오류 박스는 총 2회 미검출 후 포장작업대로 반송해 종료한다.

## 3. 공정 흐름도

| 단계 | 공정 | 주요 동작 |
|---|---|---|
| 1 | 투입·이송 | 박스 생성·간격 유지, 타원형 컨베이어 상시 순환 |
| 2 | 인식·분류 | QR 판독·3개 무동력 경사 롤러 레인 분기, 포화 시 재순환, QR 없는 박스는 재검사 후 포장작업대 반송 |
| 3 | 파레타이징 | ML 박스 위치·회전 인식, FR5 진공흡착·지정 위치 적재 |
| 4 | 운반·상차 | AMR 지게차의 파레트 인양, 출하 도크 이동·상차 |
| 5 | 출하·교체 | 차량 만재 판정, 출발·화물 제거, 다음 차량 배치 |

## 4. 구현 방식

| 단계 | 방식 | 구현 메모 |
|---|---|---|
| 이송·분류 | 혼합 | 메인 순환·QR 판독, 분기 후 무동력 경사 롤러로 중력 이송, 재순환·오류 박스 반송 |
| FR5 파레타이징 | 혼합 | ML로 박스 위치·회전 인식, IK 접근·흡착, 지정 위치 적재 |
| 운반·상차 | 혼합 | AMR 경로 탐색·장애물 대응, 포크 승강·차량 상차 |
| 공정 제어·출하 | 추상화 | 설비 간 작업 인계, 적재·만재 판정, 차량 교체·상태 표시 |

분류 카메라는 렌더링된 QR 이미지를 라이브러리로 판독한다. QR 판독에는 ML을 사용하지 않는다. 슬로프 끝의 ML 관측 카메라는 정지한 박스의 평면 위치 2축과 수평 회전각 추정에만 사용하며, 접근·흡착·파레트 적재는 IK와 스크립트로 처리한다. AMR은 Unity 내부에서 기본 경로 탐색·장애물 대응을 구현하고 ROS2·Nav2, SLAM, 다중 차량 최적화는 이번 범위에 포함하지 않는다.

### 레인별 대기·재순환

- 분류 레인은 3개이며 FR5는 레인마다 1대씩 설치한다.
- 각 픽업 구역에는 박스 한 개씩 진입시킨다. Arm과 흡착 박스가 구역에서 벗어난 뒤 다음 박스를 허용하고, 한 번에 여러 개가 통과하지 않도록 분리 제어한다.
- 레인 수용량에는 슬로프 이동 중인 박스도 포함한다. 수용 여유가 없으면 해당 레인 분기를 막고 목적 박스는 메인 컨베이어에서 계속 순환시킨다.
- 목적 레인별 재순환 대기는 최대 3개를 기준으로 해당 목적지의 신규 투입을 제한한다. 다른 레인은 정상 처리하되, 메인 전체가 혼잡하면 전체 신규 투입도 제한한다.

### 오류 시나리오: QR 코드가 없는 박스

- 일부 박스에는 의도적으로 QR 라벨을 붙이지 않는다. 라벨 훼손·오등록 코드 오류는 이번 시나리오에 포함하지 않는다.
- 박스 존재 센서로 검사 구역 진입을 확인하고, 검사 시간 동안 카메라에서 QR이 검출되지 않으면 1회 미검출로 기록한다. 프레임마다 횟수를 올리지 않고 검사 구역 통과당 한 번 집계한다.
- 첫 미검출은 한 바퀴 재순환시켜 재검사하고, 두 번째 통과에서도 미검출이면 포장작업대 반송 분기로 보낸다. 내부 추적 ID는 검사 횟수 관리에만 사용하며 QR 목적지를 대신 읽는 데 사용하지 않는다.
- 포장작업대 도착을 확인하면 반송 완료로 기록한다. 라벨 교체·재포장 동작·재투입은 구현하지 않는다.
- 반송 구간의 수용 여유가 없으면 반송 대기로 재순환하고 알람을 표시한다. 혼잡 시 신규 투입을 제한하며 오류 박스를 정상 레인에 보내지 않는다.

## 5. 어려운 점

- 박스를 물리적으로 잡으면 미끄러지거나 떨어짐 → 흡착 지점에 닿으면 박스를 붙이고, 적재 위치에서 떼는 방식으로 처리.
- 슬로프 도착 후 박스 위치·회전이 달라짐 → 박스 1종과 제한된 관측 구역에서 위치·회전을 학습하고, 인식 결과로 픽업 위치를 보정.

## 6. 디지털 트윈 요소

- 데이터: 시간당 박스 처리량, 레인별 대기·재순환 수, 파레트 적재 단수, 로봇·AMR 상태, 차량 상차 파레트 수, QR 미검출·반송 완료 수.
- 이상 상황: 레인 포화 시 해당 목적지 박스 재순환·신규 투입 제한. QR 없는 박스는 총 2회 미검출 후 포장작업대로 반송해 종료.
- 공정 가시화: Unity 시뮬레이션의 설비 상태와 물류 흐름을 대시보드에 실시간 반영.

현재 기획은 가상 공정 상태 연동을 기준으로 하며 실장비 연동을 확정한 것은 아니다. AMR 장애물 감지·대기는 보조 이상 상황으로 시연할 수 있다.

## 7. MVP와 일정

- MVP (11/3): 박스 1종으로 투입 → QR 판독·3개 레인 분류 → ML 인식 기반 FR5 픽업·파레트 적재 → AMR 운반·상차 → 차량 출하까지 한 사이클 완료. 레인 포화 시 재순환과 QR 없는 오류 박스의 포장작업대 반송도 확인.
- 마일스톤: 10/27 기획·에셋 준비 / 10/28~29 씬·관측 카메라 구성 / 10/30~11/2 공정 구현·박스 인식 학습·대시보드 / 11/3 전체 공정 통합·MVP 완료 / 11/4 테스트·버그 수정 / 11/5 시연 영상·발표자료·최종 발표.

| 10/28(수)~10/29(목) | 개발 ① | 물류센터 구조물·설비 배치, 관측 카메라·조명·박스 도착 구역 구성 |

계산 기준은 높이 200mm 박스, FR5 베이스 설치면 900mm, 후방 파레트 상판 150mm, 축에서 파레트 중심까지 수평거리 750mm다. 도달 가능한 지정 적재 위치에서 최대 5단을 검증하며, 전체 파레트 면적의 5단 적재가 검증된 것은 아니다. 설비는 분류 레인 3개, 레인별 FR5 1대와 파레트 작업 위치 1개를 기준으로 한다. AMR·차량 수량은 기존 MVP안의 각 1대를 유지한 임시 기준이며, 공유 운반 처리량 검증이 필요하다. 정상 레인과 별도로 포장작업대 반송 분기를 둔다.

주요 성공 기준은 개별 설비의 고도화보다 전체 물류 공정의 연속 동작이다. 혼합 크기 적재·다중 AMR은 확장 범위로 둔다.

## 8. 확장 계획 (선택)

| 항목 | 내용 |
|---|---|
| 선택 | ■ ML　□ ROS2　□ 없음 |
| 기능 | 슬로프 도착 박스의 위치·회전 인식 1가지만 학습. 로봇 이동·흡착·적재는 IK와 스크립트 제어 |
| 담당 · 연결 테스트 | 담당자 미정 · 11/1까지 학습 모델의 추론 결과를 Unity 픽업 목표에 반영하는지 확인 |
| 전환 기준 | 11/2까지 위치·회전 인식이 불안정하면 가이드로 위치를 정렬하고 회전각 인식만 적용 |

학습 범위는 박스 1종, 슬로프 끝의 제한된 관측 구역, 윗면이 위를 향한 정지 상태로 한정한다. 박스 뒤집힘·기울어짐과 로봇 동작 전체의 강화학습은 포함하지 않는다. 학습용 정답 위치는 데이터 생성에 사용하고, ML 적용 운전에서는 카메라 추론값으로 픽업 목표를 만든다. 박스가 회전해도 구분 가능한 시각적 특징을 두거나 대칭인 각도를 동등하게 처리한다. AMR은 전체 공정의 보조 설비로 유지하며 ROS2·Nav2는 이번 범위에서 제외한다.

## 9. 멘토 피드백

- 상태: 멘토 검토 예정.
- 검토 요청: 전체 공정 MVP 범위, FR5 적재 위치·단수, 파레트 교체 중 정체 처리, 시연 일정의 타당성.
- 실제 피드백을 받은 뒤 진행 판단과 변경 내용을 기입한다.

## 작성 시 확인

- 초기 구상의 2m 적재는 현재 고정 FR5 배치에서 검증되지 않았다. 기획표에는 최대 5단 검증 목표를 사용하고, 2m 적재는 보조축 또는 로봇 변경 검토 항목으로 남긴다.
- AMR의 명칭은 유지하되, 프로젝트 제목·주요 난점·성과 지표는 전체 물류 공정 중심으로 작성한다.
- AMR로 표현하는 기본 범위에는 지도 기반 경로 탐색과 장애물에 따른 경로 재계획이 포함된다. 지정 좌표를 순서대로 이동하고 정지만 하는 구현이라면 해당 표현을 조정한다.
- 레인별 파레트 작업 위치 1개는 파레트 물체 1개만 사용한다는 뜻이 아니다. 만재 파레트 반출 후 빈 파레트를 공급하는 로직이 필요하다.
