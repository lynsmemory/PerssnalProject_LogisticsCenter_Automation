# 실제 CAD·URDF 확보 결과 — 2026-10-27

SRS와 Unity 구현에 앞선 원본 확보 단계다. 아래 파일은 실제 다운로드했으며 아직 Unity에 임포트하거나 메시 변환하지 않았다.

## 1. Syskomp 제조사 롤러 컨베이어 CAD

- 공식 안내: https://syskomp-group.com/en/products/roller-conveyors/
- 실제 다운로드: https://syskomp.tools/files/lp/wp-content/uploads/2020/10/Rollenfoerderer_20201009.zip
- 로컬 원본: `Syskomp/Rollenfoerderer_20201009.zip` — 95,460,921 bytes.
- STEP 39개. 폭 420/620/820mm 각각 직선 1종, 벨트 결합 직선 1종, 30/45/60/90도 곡선, 30/45도 합류·분기 M1/M2, 직각 이송, 지지대, 방향 전환 모듈을 포함한다.
- 폭 420mm 중 벨트 결합 직선을 제외한 12개를 `Syskomp/STEP_420mm/`에 추출했다. 420mm는 검토용 선택이며 박스 평면 크기가 확정되지 않아 최종 폭은 아니다.
- ZIP 전체 CRC 통과. STEP 39개 모두 ISO-10303-21 시작·종료 표식 확인. 각 파일 크기·SHA256·솔리드 엔터티 수는 `Syskomp/file_manifest.json`에 기록했다. CAD 커널로 형상 복구·렌더링한 검사는 아직 하지 않았다.

### 이번 공정에 적용할 부분

- **실제 확보한 파일명은 SKZS/SKZC/SKZM 등 구동·구역제어형이다. 무동력 SKNDS 완제품 STEP를 확보한 것은 아니다.**
- 메인 타원 순환부: 직선과 90도 곡선 모듈을 조합하는 외형 기반. 90도 4개와 직선 2구간으로 타원형에 가까운 레이아웃을 설계할 수 있다. 실제 접속 치수는 변환 후 확인한다.
- 분류 구간: SKZM/MAD 등의 실제 형상을 참고하되, 합류용 모듈의 역방향 사용이 곧 능동 분기 동작을 뜻하지 않는다. 분기 액추에이터·제어는 별도 구현한다.
- 중력 레인: 공식 제품군은 무동력 SKNDS/SKNDC/SKNDM을 제공한다. 확보한 구동형 CAD에서 구동부를 제외하고 롤러·프레임을 재구성하는 **파생 모델**이 필요하다. 지지대 높이·경사·스토퍼도 별도 설계한다. 수정본을 제조사 무동력 완제품과 동일하다고 표기하지 않는다.
- 공식 페이지의 무동력 제품 경사 범위는 ±3도. 박스가 스스로 출발하는 각도·속도는 실제 박스 바닥, 롤러 저항, Unity 물성값에 따라 달라지므로 3도에서 반드시 흐른다고 가정하지 않는다.
- 공식 기본 피치는 75/100mm. 박스 **높이** 200mm만 확정되어 있다. 이송 방향 바닥 길이도 200mm라면 최소 3개 롤러 지지를 목표로 피치 약 66.7mm 이하가 필요하므로 기본 CAD를 그대로 쓰지 않는다. 60mm 피치 등으로 재배치할지는 바닥 크기 확정 후 판단한다.

제조사에서 무료 CAD 다운로드를 제공하지만 원본 자산 재배포 및 수정 모델 공개 범위를 명시한 라이선스는 아직 확인하지 못했다. 공개 저장소/배포 빌드에 원본을 넣기 전 확인이 필요하다. 국내 업체 또는 쿠팡 사용 제품으로 확인된 모델이 아니다.

## 2. FAIRINO FR5 공식 URDF + STL 전체 세트

- 공식 저장소: https://github.com/FAIR-INNOVATION/frcobot_ros2
- 기준 커밋: `867cb32bc24a73c1e60bef4e6c16762e7357c5e1`
- 파일: `FR5/fairino_description/urdf/fairino5_v6.urdf`
- 연결 메시: `FR5/fairino_description/meshes/fairino5_v6/`의 STL 7개.
- URDF XML 파싱 및 모든 mesh 참조 파일 존재 확인. STL 7개 모두 바이너리 삼각형 수와 파일 길이 일치 확인. 상세 기록은 `FR5/file_manifest.json`.
- `package://fairino_description/...` 경로를 유지했다. Unity 임포트 시 패키지 루트를 지정해야 한다. 시각화·관절 구동·충돌 검사는 아직 하지 않았다.
- `package.xml` 라이선스가 `TODO: License declaration` 상태다. 공개 다운로드와 자유로운 재배포 허가는 구분한다.
- 베이스 900mm, 후방 파레트, 흡착 툴/TCP, 실제 플랜지 위치 보정과 적재 도달성 검증은 별도 작업이다. URDF가 그 동작까지 제공하지 않는다.

## 아직 확보하지 못한 원본

국내 컨베이어 업체 및 쿠팡에 공급된 특정 장비의 실제 공개 3D CAD/URDF는 이번 조사에서 확보하지 못했다. MK의 무동력 RBS-P CAD 구성 페이지는 찾았으나 실제 파일을 받지는 못했다. AMR 지게차·흡착 툴·플라스틱 파레트의 최종 제품 원본도 미선정이다.

현재 확보한 CAD를 기준으로 한 다음 작업은 형상 열기 → 단위/축 확인 → 필요한 부품만 메시 변환 → URP 재질 → 단순 충돌체 → 이송·센서·스토퍼 제어다. SRS와 씬 구현은 시작하지 않았다.
