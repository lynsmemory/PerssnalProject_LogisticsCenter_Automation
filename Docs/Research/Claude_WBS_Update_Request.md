# Claude WBS 수정 요청

현재 SRS를 기준으로 기존 WBS를 수정해 주세요. SRS의 요구사항 내용은 변경하지 말고 WBS의 작업 구성, 요구사항 연결, 일정, 완료 조건을 맞춰 주세요. 담당자가 정해지지 않은 작업은 임의로 배정하지 말고 미정으로 남겨 주세요.

## 기준 파일

- `Docs/SRS_LogisticsCenter_v1.0.docx`
- `Docs/Research/SRS_Draft_Source_Facts.json`

## 반영 사항

- 기능 요구사항은 FR-01부터 FR-24까지, 시험은 TC-01부터 TC-31까지 연속 번호입니다. 삭제된 번호를 빈칸으로 유지하지 않습니다.
- FR-01은 건물과 공정 구역 배치, FR-02는 카메라 전환입니다. 씬 구성 작업을 가장 먼저 배치하세요.
- 10/28~10/29 씬 구성, 10/30~11/2 핵심 공정 구현, 11/3 MVP 완료, 11/4 통합 시험과 수정, 11/5 발표입니다.
- CNN 이미지 인식은 FR-24의 선택 확장입니다. 11/4 통합 시험 후 여유가 있을 때만 적용합니다. ML-Agents와 ROS2, Nav2 작업은 넣지 마세요.
- CNN 없이 끝 스토퍼와 측면 가이드로 픽업 위치와 수평 회전을 고정합니다. 중간 대기 스토퍼와 끝 스토퍼는 별도입니다.
- 레인별 순환 대기 최대 3개, 중간 스토퍼 앞 1개, 픽업 또는 로봇 취급 중 1개로 총 5개입니다. 순환 대기 3개에서 해당 바코드 새 박스 투입을 중지하고 알람을 표시합니다. 정체 후 2개에서는 유지하고 1개 이하에서 해제합니다. 기존 박스는 계속 순환하고 빈 레인으로 분기합니다.
- 레인 1/AMR 1/도크 1의 차량, 레인 2/AMR 2/도크 2의 차량, 레인 3/AMR 3/도크 3의 차량을 전담 연결합니다.
- 적재는 층당 6자리를 반드시 채웁니다. 기본은 3층 18개와 차량당 10파레트, 시연은 2층 12개와 차량당 3파레트입니다. 적재 층 수 L과 차량 만재 수량 N을 설정값으로 분리하세요.
- 박스 360×280×340mm, 2kg, 파레트 1100×1100×150mm, FR5 베이스 950mm, 흡착 툴 길이 182.8mm입니다.
- 바코드는 Code 128, L01/L02/L03입니다. 미판독 오류 처리는 MVP에서 제외합니다.
- 상차 실패 재시도와 성능 수치 등 아직 미정인 항목은 SRS대로 시뮬레이션 시험 후 결정하세요.
- 새 끝 스토퍼와 측면 가이드를 포함한 간섭 확인과 전체 공정 시험을 WBS에 넣으세요. 기존 CAD 경로 검사를 Unity 전체 공정 시험 완료로 처리하지 마세요.
- 기능 개발과 관련 TC 시험, 통합 시험, 발표 준비를 구분해 완료 조건을 적어 주세요. 임의로 Git에 커밋하거나 푸시하지 마세요.
