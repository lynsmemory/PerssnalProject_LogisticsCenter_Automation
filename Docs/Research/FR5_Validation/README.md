# FR5 적재 경로 검사 결과

검사일 2026-10-27

## 반영한 안

- 박스 360×280×340mm, 질량 2kg
- 파레트 1100×1100×150mm
- FR5 베이스 설치면 높이 900mm
- 각 층 6개를 모두 채운 뒤 다음 층 진행
- 3단 18개에 적재 완료, 파레트 포함 높이 1170mm

380×350×340mm의 2단 12개도 검토한 경로의 샘플 검사를 통과했다. 수량이 더 많은 360×280×340mm 안을 SRS 초안에 반영했다. 서로 다른 높이로 쌓는 14개 안은 적용하지 않는다.

## 검사한 대상

공식 FR5 STL 7개로 로봇 형상을 구성했다. 로봇의 인접 링크는 관절 연결 부분이므로 서로 간 충돌 검사에서 제외했고, 그 외 링크끼리는 검사했다. 받침대, 바닥, 파레트, 단순화한 흡착 툴, 운반 중인 박스, 이미 적재한 박스를 함께 넣었다. 파레트는 내부가 막힌 직육면체로 모델링했다.

박스는 먼저 먼 줄의 양 끝과 가운데를 채우고, 가까운 줄의 양 끝과 가운데를 채웠다. 한 층의 6개가 끝나기 전에는 다음 층을 시작하지 않았다. 박스를 싣고 이동하는 경로와 해제한 뒤 빈 툴로 돌아오는 경로를 모두 검사했다.

| 후보 | 층 수 | 검사 기록의 왕복 관절 자세 수 | 결과 |
|---|---|---|---|
| 380×350×340mm | 2 | 21,716 | 선택한 경로의 샘플에서 충돌 없음 |
| 360×280×340mm | 3 | 34,624 | 선택한 경로의 샘플에서 충돌 없음 |

위 수는 최종 선택 경로의 기록 수다. 경로를 찾는 중 충돌하거나 이어지지 않아 버린 자세까지 모두 통과했다는 뜻은 아니다. 양쪽 모두 여러 관절 해를 비교했고, 첫 번째 해를 그대로 연결하면 막히는 경우가 있었다.

## 검사 치수

- 로봇 축에서 파레트 가까운 변까지 150mm
- 받침대 가로와 세로 200mm, 파레트와 사이 50mm
- 박스 사이 10mm
- 플랜지에서 흡착점까지 125mm
- 적재점 위 국소 접근 거리 100mm
- 픽업 시험점은 로봇 앞쪽 (450, 0, 650)mm
- 박스 6개의 중심은 후방 기준 x=-330mm와 -700mm, y=-290mm, 0mm, +290mm
- 박스 접촉면은 수치 오차로 접촉을 겹침으로 계산하지 않도록 각 면에서 1mm 안쪽으로 검사
- 관절 자세 사이 검사 간격은 각 축 최대 0.008rad 이하

운반 박스는 툴에 붙은 강체로 검사했다. 관절 자세가 바뀔 때 박스도 함께 움직인다. 높이가 이미 쌓인 박스보다 낮은 상태에서 그 위를 가로질러 가지 않도록, 이동 높이와 내려오는 위치를 따로 잡았다.

## 아직 검사하지 않은 부분

이번 결과는 위 치수의 단일 가상 셀에 대한 형상 및 경로 샘플 검사다. 다음을 보장하지 않는다.

- 샘플 사이 모든 순간에 대한 연속 충돌 검증
- 가속도, 진동, 박스 변형, 진공 유지, 손목 하중과 실기 동작
- 실제 슬로프 끝단의 픽업 위치와 ML 위치 오차
- 레인 3개, FR5 3대, AMR 3대와 차량을 모두 배치한 전체 씬의 통행
- 지게차 운반 중 화물의 안정성

픽업 시험점과 받침대, 흡착 툴은 이번 검사용 치수다. 실제 씬의 치수로 자동 확정하지 않는다. Unity에서 구현할 때 같은 경로를 재현하고, 실제로 배치한 설비와 다시 시험해야 한다.

## 파일과 재현

- `verify.py`: STL 로딩, FK, 여러 IK 해, 로봇과 박스의 충돌 검사
- `path.py`: 층별 적재 순서와 운반 및 복귀 경로 계산
- `validation_summary.json`: 최종 기록 요약
- `trajectory_360_280.npz`: SRS에 반영한 경로의 관절 자세
- `trajectory_380_350.npz`: 비교한 12개 안의 관절 자세

사용한 충돌 라이브러리는 python-fcl 0.7.0.11이다. NumPy와 기존 기구 계산 코드도 사용했다. 라이브러리는 임시 폴더에 설치했으며 Unity 패키지는 변경하지 않았다. `path.py`는 같은 폴더의 검사 코드를 읽으며 결과를 같은 폴더에 저장한다. 재실행 시 그 결과 파일을 갱신하므로 보존할 결과가 있으면 먼저 복사한다.

근거 모델은 `../CAD_References/FR5`의 FAIRINO 공식 URDF와 STL이다. 관절 계산에서 URDF의 반올림된 π/2 값은 정확한 π/2로 사용했다. 이 차이와 검사 간격 때문에 실제 로봇 정밀도를 주장하지 않는다.
