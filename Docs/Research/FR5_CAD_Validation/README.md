# 실제 Schmalz CAD를 적용한 FR5 적재 검사

검사일: 2026-10-27

## 결과

기존 베이스 높이 900mm와 단순 툴 125mm의 검사 결과를 실제 Schmalz 툴에 그대로 적용할 수 없다. 실제 CAD 조립의 플랜지부터 흡착면까지 길이는 182.8mm다.

| 조건 | 결과 |
|---|---|
| 베이스 900mm, 기존 운반 경로 | 모든 적재점과 100mm 위 접근점에 충돌 없는 정지 자세는 존재한다. 그러나 14번째 박스 운반을 위한 상승 구간에서 도달 범위를 벗어나 18개 왕복 경로를 완성하지 못했다. |
| 베이스 900mm, 운반 높이와 가까운 줄의 적재 순서를 바꾼 경로 | 8번째 박스 이동 구간에서 경로를 찾지 못했다. 이 실패를 가능한 모든 경로의 실패로 해석하지 않는다. |
| 베이스 950mm, 기존 운반 경로 | 각 층을 모두 채우는 순서로 3단 18개 운반과 빈 툴 복귀를 모두 검사했다. 선택 경로의 34,750개 왕복 관절 자세 샘플에서 검사 대상끼리 충돌이 없었다. |
| 베이스 900mm 또는 950mm, 동일 6개 배치의 4단 | 먼 줄의 박스 윗면 1510mm에 수직 툴로 닿지 않는다. 따라서 한 층 전체를 채우는 4단은 불가능하다. |

950mm는 추가 비교한 제안이다. 기존 SRS의 설치 높이를 임의로 변경하지 않았다. 높이 조정 없이 900mm에서의 3단을 불가능하다고 증명한 것은 아니지만, 이번에 검사한 두 경로로는 완료하지 못했다.

## 치수와 계산

박스 360×280×340mm, 질량 2kg, 파레트 1100×1100×150mm다. 로봇 축에서 파레트 가까운 변까지 150mm다. 박스 사이 간격은 10mm이며 접촉점 위 접근 거리는 100mm다. 한 층은 먼 줄의 음의 Y, 양의 Y, 가운데를 채우고 가까운 줄도 같은 순서로 채운다. 각 층을 모두 채운 뒤 다음 층으로 넘어간다.

박스 중심은 x=-700mm와 -330mm, y=-290mm, +290mm, 0mm다. 박스 바닥 높이는 150mm, 490mm, 830mm이고, 각 층 윗면은 490mm, 830mm, 1170mm다. 18개 완료 시 바닥에서 높이는 1170mm다. 시험 픽업점은 로봇 앞쪽 (450, 0, 650)mm이며 실제 레인의 확정 치수는 아니다.

가장 먼 두 접촉점의 반지름은 약 757.694mm다. 수직 툴의 기구학상 윗면 도달 한계는 베이스 900mm에서 1270.694mm, 950mm에서 1320.694mm다. 3단 위 100mm 접근점은 1270mm이므로 이 한계까지의 수직 여유는 각각 약 0.694mm와 50.694mm다. 이 수치는 장애물과의 거리나 보장된 작업 오차가 아니다. 900mm 조건은 명목 치수만으로도 도달 한계에 너무 가깝다.

950mm 결과의 관절 한계까지 최소 여유는 약 8.112도다. 관절 샘플 간 최대 축 변화는 0.007999rad 미만이다. 경로 탐색 중 검사 호출 수는 83,730회이며, 실패한 후보의 검사도 포함한다. 최종 선택 경로의 통과 자세 수와 다르다. FK로 확인한 최종 접촉점 계산 오차는 1e-12m 미만이고, 이는 계산식 검산 결과로 실물 정밀도를 뜻하지 않는다.

## CAD 조립 방법

입력 3종은 모두 STEP AP242이며 mm 단위다. 원본은 Docs/CAD에 있다. cad_solids.json에 각 솔리드의 치수와 위치를 기록했고 tool_assembly.json에 원본 SHA-256, 선택한 솔리드와 변환을 기록했다.

- 10.03.01.00988은 진공 발생기, FR5 장착부, QCM 및 기본 1컵 툴을 포함한다. 기본 1컵의 헤드와 연결부, 컵은 제거했다.
- 10.01.36.00269는 벨로즈와 평형 컵 대안을 별도 위치에 함께 포함하고, 글자 형상도 포함한다. 원점 주변의 벨로즈 4컵 구성만 선택했다. 두 대안을 합친 전체 경계상자를 툴 치수로 사용하지 않았다.
- 벨로즈 4컵 헤드의 CAD 좌표 연결면은 Z=0, 흡착면은 Z=-87mm다. FR5 세트의 헤드 연결면 Y=-95.8mm에 맞추었다.
- 로봇 장착면은 세트의 장착 플레이트 솔리드 11의 큰 평면 Y=0이다. Y=+5mm의 작은 돌출부는 위치 결정 부분으로 보고 장착면에 더하지 않았다.
- 따라서 플랜지부터 비압축 흡착면까지는 95.8+87=182.8mm다. 전체 형상의 후방 돌출 6mm를 포함하면 외형 높이는 제품 도면의 188.8mm와 일치한다.
- 조립 툴의 외곽은 약 174.05×174.05mm이며, 플랜지 기준 툴 축 범위는 -6mm에서 +182.8mm다. 흡착컵 중심은 가로와 세로 각각 ±62.225mm다.
- 4컵 헤드 CAD에 컵이 이미 포함되어 있으므로 SPB1 단품을 중복 부착하지 않았다. 별도 받은 단품은 형상 대조 자료로 보관했다.
- 공급 CAD의 케이블은 설치 경로가 정해지지 않은 직선 상태다. 케이블 본체와 그 끝단은 강체 툴에서 제외했다. 진공 발생기 쪽 커넥터는 포함했다. 케이블 설치 경로 검사는 남아 있다.

assembled_tool_views.png에서 선택한 조립 형상과 컵 배열을 확인할 수 있다. assembled_tool_m.npz는 이를 미터 단위 삼각형 메시로 바꾼 검사 입력이다. CAD의 곡면 삼각형 분할 설정은 선형 편차 0.15mm, 각도 0.25rad다.

## 검사 범위와 남은 확인

FR5의 공식 STL 7개와 실제 조립 툴 메시를 검사했다. 로봇의 인접 링크끼리, 툴과 장착되는 wrist3 링크는 접합부 검사에서 제외했다. 툴과 wrist2 및 그 이전 링크는 검사했다. 바닥, 받침대, 파레트, 이미 적재한 박스, 운반 박스를 포함했다. 박스 형상은 각 면에서 1mm 안쪽으로 줄인 접촉 수치 허용을 적용했다. 로봇과 실제 툴 자체는 같은 방식으로 줄이지 않았다.

연속 충돌 검사나 실기 시험은 수행하지 않았다. 샘플 사이 충돌, 가속도, 진동, 진공 누설, 흡착컵 압축, 박스 변형, 손목 하중과 관성, 케이블 경로를 보장하지 않는다. 전체 툴의 제조사 질량은 아직 확정되지 않아 2kg 박스를 포함한 FR5 가반하중도 최종 승인하지 않는다. 3개 셀과 AMR 통행, 실제 레인 구조물은 이번 단일 셀 검사에 포함하지 않았다.

## 재현 파일

- inspect_cad.py, export_cad.py: OpenCascade로 STEP 솔리드 측정과 삼각형 메시 생성
- build_tool.py: 선택한 부품 조립
- verify.py: 실제 툴 형상과 정지 자세 검사
- path.py: 베이스 900mm의 기존 경로 검사
- path_local.py: 베이스 900mm의 변경 경로 검사
- path_950.py: 베이스 950mm의 기존 경로 검사
- audit_results.py: 성공 경로의 FK, 관절 범위와 샘플 검사 간격 검산
- static_results.json, path_results*.json, height_limits.json, validation_summary.json: 검사 결과
- trajectory_950_360_280.npz: 성공한 18개 운반 경로. 각 경로를 역순으로 빈 툴 복귀에도 검사했다.

기존 FR5_Validation의 기록은 수정하지 않았다. NumPy, Matplotlib, python-fcl 0.7.0.11과 cadquery-ocp-novtk 7.9.3.1.1을 사용했다. CAD 라이브러리는 /tmp/logistics-cad-libs, FCL은 /tmp/logistics-fr5-validation-libs에 임시 설치했으며 Unity 패키지는 변경하지 않았다. 스크립트의 임시 라이브러리 경로는 다른 PC에서 설치 위치에 맞게 조정해야 한다. STEP 재변환 시에는 PYTHONPATH에 CAD 라이브러리 경로를 추가한다. 조사 스크립트는 프로젝트 루트에서 실행한다.
