## 검수에서 발견한 불일치

1. **물리 시험 박스 규격:** `Assets/Editor/ConveyorLayoutBuilder.cs:778`은 크기 0.35×0.34×0.48m, 780행은 질량 3kg이다. SRS는 360×280×340mm·2kg이다. 따라서 기존 물리 로그는 시험용 박스의 결과이며 SRS 박스의 합격 근거로 사용할 수 없다. Claude 수정 요청: 폭·깊이·높이 축 대응을 명시해 SRS 규격으로 TestBox를 수정하고 6초·10초 간격 시험을 재실행. 씬 Build는 자동 재실행하지 말 것.
2. **FR5 기록:** WBS 13행은 Import 완료지만 현재 Assets 파일 목록에는 FR5·fairino·URDF 모델을 확인하지 못했다. 공식 원본 `Docs/Research/CAD_References/FR5/fairino_description/urdf/fairino5_v6.urdf`와 같은 패키지의 STL 7개는 다운로드되어 있다. 원본 확보 완료와 Unity 임포트·프리팹 생성을 구분해야 한다.
3. **상태 문구:** CLAUDE.md는 아직 연동 확인만 완료·구현 보류라고 되어 있어 최신 사용자 직접 지시 및 실제 작업과 맞지 않는다. 최신 승인 범위를 정확히 반영할 필요가 있다.
