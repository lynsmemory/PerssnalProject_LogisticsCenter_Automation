# 파레트 제작 및 WBS 반영

2026-10-28 사용자 지시로 Codex가 직접 제작했다. Claude 호출·추가 작업 지시는 하지 않았다. 신규 제작·자동화 스크립트 파일은 프로젝트에 추가하지 않았다.

## 파레트

- 에셋: `Assets/LogisticsVehicles/Pallet_1100x1100x150.prefab`.
- 크기 X/Y/Z = 1.100/0.150/1.100m. 원점은 바닥 중심, 상면 Y=0.150m.
- 상판 5개, 하판 3개, 지지 블록 9개와 나사 표현 20개. URP Lit 목재색 재질 3종을 추가했다.
- 구성 부재별 BoxCollider 17개로 포크 통로를 비웠다. 전후 진입 기준점과 적재 상면 기준점, 3열×2행 슬롯 기준점 6개를 포함한다. 슬롯은 층 바닥 기준이며 박스 중심 높이는 운용 코드에서 더해야 한다.
- 포크 통로 폭 0.325m, 하판 위~상판 아래 여유 높이 0.100m. 지게차 실제 포크와의 간섭·인양 시험은 아직 수행하지 않았다.
- Rigidbody·운반·적재 스크립트는 포함하지 않는다. AMR 운반 연결 시 필요한 물리 설정을 정한다. 셀 위치는 내일 지정하므로 씬에 배치하지 않았다.
- 파일 검사: 중복 ID 없음, 로컬 참조 유효, 전체 외곽 치수 일치.
- Unity 6000.6.0f1 별도 임시 프로젝트 임포트·기존 VehiclePrefabPreview 도구 실행 종료 코드 0. 메시/재질/법선 검사 37개 통과, failures=0. 4방향 렌더 확인. 임시 경로에서만 프리팹 파일명을 기존 렌더 도구의 고정 경로에 맞춰 사용했다.
- 한계: 렌더는 Standard 재질 대체 방식이다. 원본 프로젝트 URP 화면·포크 인양·적재 TC는 실행하지 않았다.
- 결과: `Pallet_Prefab_Validation_2026-10-28.json`, `PalletPreview_2026-10-28/`.

## 사용자 결정

- 박스 투입 위치: 현재 컨베이어 최상단 끝의 기존 `ConveyorSystem/EntryLine/UpperEntryStart`.
- FR5 셀 3곳과 카메라 최종 지정: 10/29.
- SRS 박스 규격에 대한 물리 재시험: 신규 에셋 적용 후. 기존 규격 문제는 재시험 대기이며 합격 처리하지 않는다.
- Claude의 오늘 작업은 종료. 추가 호출하지 않는다.

## WBS 반영

- 실적 기준일 L1을 2026-10-28로 변경했다.
- 오늘 배치 완료일 반영: 20행 외벽·바닥, 24행 도크, 25행 순환 컨베이어, 26행 분기 3개, 27행 경사 레인 연결. 이는 배치 완료이며 SRS 규격 물리 TC 통과가 아니다. 롤러 외형 에셋 교체는 후속으로 유지한다.
- 12행은 새 파레트 프리팹 제작 완료일을 10/28로 갱신했다. 기존 파일에는 10/27 완료로 기록되어 있었으나 이번 신규 결과의 제작일로 정정했다.
- 21·22행은 경계 표시 미완료, 23·36행은 최종 지정 대기이므로 완료일을 채우지 않았다. 투입점 확정만으로 구역 경계까지 완료 처리하지 않는다.
- B113 비고에 투입점 확정·셀/카메라 내일 지정·규격 시험 연기 결정을 기록했다. 기존 계획일과 완료 조건은 유지했다.
- P20이 N21을 참조하고 P21에 #REF!가 있던 실제 기간 수식을 각 행의 N20·N21 참조로 수정했다. 공유 수식과 진척률을 다시 계산했으며 저장본 수식 오류 0건을 확인했다.
- 기존 서식·조건부 서식 확장·공유 수식·휴일 시트 등을 보존했다. XLSX 내부에서는 첫 시트 값/수식 캐시와 재계산 설정만 변경되었다. 기타 입력·수식이 바뀌지 않았음을 비교했다.
- 백업: `WBS_before_update_2026-10-28.xlsx.bak`.

기존 WBS의 FR5 Import 등 역사적 완료 기록은 이번 요청 범위에서 변경하지 않았다. 원본 URDF/STL 확보와 Unity 임포트 상태의 불일치는 앞선 감사 기록을 유지한다.
